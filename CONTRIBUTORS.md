## How to Become a Contributor

We welcome contributions of all kinds! See [README.md#contributing](README.md#contributing) for detailed contribution guidelines.

### Ways to Contribute

- 🐛 **Bug Fixes** - Find and fix bugs
- ✨ **Features** - Add new game mechanics or systems
- 📝 **Documentation** - Improve guides and examples
- 🎨 **Content** - Create floors, enemies, items, or art
- 🧪 **Testing** - Add test coverage
- 💬 **Support** - Help others in discussions
